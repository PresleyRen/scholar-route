## 结论与建议顺序

**在这份教学案例的记录条件下，优先考虑 Fictional Journal A；Fictional Journal B 是费用待核实的条件备选；Fictional Conference C 因为是会议而排除。材料只能支持 1 本记录内合格期刊，不能支持 3 本合格期刊。** A 的优先级来自硬约束证据更完整；现有材料没有证明它更容易录用。[F0]

这里的“合格”仅指合成记录通过了“期刊、SCIE、零强制费用”等检查。输入明确设置 `fictional: true`；期刊、论文、来源和数值都属于教学设定。**本次实际核实的真实期刊数为 0。** 没有访问示例网址，没有收到论文摘要正文或全文，也没有执行稿件所述实验。输入中的 `verified: true` 和 `read_status: abstract` 均保留为原始案例状态，不能解读为本次完成了相应外部核验或论文阅读。[F0]

建议顺序为：**A → B（仅在费用及逐刊适配证据补齐后）→ 第三本待补充材料**。C 不进入该顺序。

## 3. 候选档案与首投理由

### 3.1 Fictional Journal A：首要考虑与核实对象

**案例身份：** ISSN `1234-5679`，出版方 `Fictional Publisher A`，类型为期刊。SCIE、0 USD 强制费用总额、费用完整性标志均为记录内已验证，关联来源分别为 `fixture-index` 与 `fixture-publisher`。[F0]

**首选依据：** A 是现有材料中唯一同时通过全部硬约束检查的对象。对于“无强制费用”的明确要求，这比 B 的未知费用状态更有可操作性。A 还关联了一条刊名与自身一致的论文记录 `paper-one`，但这只提供了有限的教学线索。[F0]

**不能从现有材料推出的结论：** 没有实际刊物身份、当前官方 scope、所接收文章类型、完整作者指南、投稿周期、分区或真实录用统计。输入没有给出 A 的具体出版路线 `oa_route`，也没有费用分项或适用条件的原文。程序认可“0 + 全部强制费用已包含”的标记，不等于人工已核实本稿通过哪条路线实现零强制费用。[F0]

因此，在教学题里可把 A 放在第一顺位；落实为真实投稿前，要取得实际对象的官方材料，确认无条件适用的出版路线，并审查本稿与该刊的具体匹配。若核实后存在强制收费、范围不符或文章类型不被接受，就应重新筛选。

### 3.2 Fictional Journal B：费用待核实的条件备选

**案例身份：** ISSN `2049-3630`，同属 `Fictional Publisher A`，期刊与 SCIE 字段记录内通过；`mandatory_fee` 完全缺失。[F0]

**保留价值：** B 目前没有记录内已知违反的硬条件，值得保留费用核实任务。由于其唯一关联论文也指向 A，仍需补 B 自身的官方 scope 和可比论文，才能形成逐刊匹配判断。[F0]

**费用核实后的处理规则：**

- 若取得适用于本稿文章类型与出版路线的证据，确认全部强制费用总额为 0，且不依赖未确认的减免，则 B 可进入合格池。
- 若明确存在大于 0 的强制费用，则在当前预算下排除。
- 若只知道 OA 选项价格、只看到“可能减免”、缺少版面等费用项目，或适用性尚未确定，则继续待核实。

这三个分支是后续核实的决策规则，当前材料并未给出其中任何一种最终费用结果。不能因为 A、B 同属一个虚构出版方，就把 A 的 0 USD 复制给 B。

### 3.3 Fictional Conference C：明确排除

**案例身份：** ISSN `2434-561X`，同属 `Fictional Publisher A`；类型明确是 `conference`。输入也给了它 SCIE 与 0 USD 标记，这些都继续作为原始合成数据保留。[F0]

**排除依据：** 用户要求投稿对象必须是期刊。会议的主题再相关，也不能作为第三本期刊候选。这里无需推翻或修补它的其他合成字段，出版类型已经决定了排除结果。

## 4. 为什么三个 4/5 不能决定首投

三项 `fit` 完全相同：分数 4、理由为机制和读者相符、日期为 2026-10-20；它们共同链接 `fixture-paper` 和 `paper-one`。[F0]

`paper-one` 的题名为 *Fictional equal-budget Agent recovery study*，年份 2025，所载刊名为 Fictional Journal A，DOI 为合成标识 `10.5555/scholarroute-fixture-1`。原始 `read_status` 为 `abstract`，但输入没有包含摘要内容，更没有全文。因此本次能检查的是记录与引用关系，无法独立复核“机制和读者相符”的判断。[F0]

这里有三层证据限制：

1. **给定分数没有提供排名差异。** A、B、C 都是 4；A 的优先次序来自资格与费用证据完整性。
2. **同一论文不构成三份独立的逐刊证据。** 即便它在 A 中确有相关性，也不能自动证明 B、C 的 scope 或收稿偏好。
3. **记录的阅读状态不能替代本次实际阅读。** 本报告没有宣称读取到摘要或全文，也没有把合成 DOI 当成已验证的真实文献。

为保护来源与历史，原始 fit 未删除、未补分、未改成新的主观分数。自动导出文件中的 4/5 仍然是案例输入；人工报告不将它用作稿件准备度、录用概率或“好投”的证明。
