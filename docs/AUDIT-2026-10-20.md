## 结论与本轮修改

原讨论清单中的 17 个现行来源仓库均在来源注册表内，139 条模块/子模式/领域变体映射均指向有效能力。41 项能力均有来源映射和工作流文件。33 条冲突现已逐条关联程序测试或工作流场景。

本轮补齐的主要缺口是**可追踪性与验收入口**：此前有冲突规则和来源表，但没有一条直接连接“症状—特点—能力—实现—测试”的维修路径。新增索引、查询工具、负向测试和场景记录后，可以从中文症状、能力 ID 或上游技能名称定位修改位置。

## 代表性冲突的实际处理

| 固定输入 | 运行后结果 | 保留的方案 |
|---|---|---|
| 医学/食品中的 LLM Agent | 同时保留 PubMed、DBLP、arXiv、AGRICOLA 与相关研究模块 | 交叉领域互补，而非用一种学科覆盖另一种 |
| 普通抗菌药物研究中的 antimicrobial agents | 路由到 biomedicine，未激活 LLM Agent 模块 | 区分科学术语语境 |
| 已核实费用超过预算，同时索引未知 | excluded，并保留索引 unknown 检查项 | 确定性违反优先，其他信息仍保留 |
| 可选 OA，已核实必缴费用为零 | 满足零必缴费用约束 | 按实际路径判断，不把可选费强加给作者 |
| 同一体系/年份/类别同时 Q1 与 Q3 | 两条事实保留，候选进入 unverified | 保留矛盾，不自动选择更好分区 |
| 同一冲突重复导入后给出有证据的解决 | 重复导入不新增修订；显式解决保留前后事实 | 幂等导入与审计历史互补 |
| 初次决定 2 天、外审 50 天、录用 110 天、发表 125 天 | 四个字段分别保存原值 | 时间端点保持独立 |
| 仅 1 个有效候选，却请求 5 个 | 返回 1 个 | 数量随证据，不填充虚构条目 |
| 高适配分但评估过时 | 保留候选，未以过时分挤掉当前候选 | 资格与有效适配评价分离 |
| 候选无适配分 | 保留为未排序 eligible，分数仍为 None | 缺值与零分分离 |
| 旧项目用英文/新预算参数重新初始化 | 原语言、预算和文件字节保持一致 | 默认恢复现有项目 |

18 条程序冲突并非每条都新建一个测试；部分直接关联已有、已重跑的回归。准确 CF→测试对应关系在 [COVERAGE.md](COVERAGE.md)。

## 15 个工作流场景

本次助手对固定合成输入逐项应用工作流并记录产物，覆盖质量判断、可比论文数量、出版风险、商业平台、润色保真、作者贡献、多视角审稿、发送权限、项目续做、外部工具、许可、格式与科学审查、更正、分区选择。

每条记录包含输入、实际处理文本、保留两种流程的哪些部分及检查结果，见 [WORKFLOW-REVIEW.md](WORKFLOW-REVIEW.md)。这些是本次助手执行的定性场景审查，独立于 Python 测试；不是跨模型盲测或真实投稿成功率评估。

## 端到端示例

实际运行：

```bash
python examples/run_demo.py --project ./work/audit-v110
python skills/scholar-route/scripts/scholar_route.py validate --project ./work/audit-v110
```

合成输入产生：

```text
eligible:   journal-a
unverified: journal-b  [必缴费用缺失]
excluded:   venue-c    [会议，不符合期刊约束]

project valid: true
revision: 10
sources: 3 / papers: 1 / venues: 3
claims: 1 / hypotheses: 1 / experiments: 1
warnings: []
```

导出 `REPORT.md`、`MAP.md`、`journals.csv`、`references.bib`、`assessment.json`，五个文件均存在且内容可读取。所有名称与事实均为测试用合成材料。

## 负向验证：索引真的能发现缺口吗

新增测试主动移除来源、清空能力映射、增加未知能力、改成未固定版本的来源 URL、删除工作流文件、删除测试、重复特点名称以及删除场景记录。相应检查均报告错误；正常注册表保持通过。

定位命令也实际运行：

```bash
python tools/coverage_audit.py --find "费用"
python tools/coverage_audit.py --find agent-systems
python tools/coverage_audit.py --find journal-recommender
```

费用返回 `costs-timelines` 及 `venue_audit.py` / `project_store.py`；系统研究返回 `agent-research.md`；来源名返回关联能力。未知查询返回空结果和 exit 3，空查询返回 exit 2。
